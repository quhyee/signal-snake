# Signal Snake 中文界面设计

## 目标

将 `Signal Snake` 的玩家可见界面与使用说明文档改成中文版，同时保留当前复古街机的视觉气质，不改动核心玩法与存档逻辑。

## 决策

- 保留品牌名 `Signal Snake` 作为主标题，避免破坏当前标题字体风格。
- 将页面说明、按钮、HUD 标签、状态文本、覆盖层提示、无障碍播报和 `README` 全部改为中文。
- 将动态运行时文案集中到一个独立模块中，避免 `main.js` 和 `renderer.js` 出现分散的硬编码字符串。

## 视觉与排版

- 正文字体切换为更适合中文的字体栈，优先系统中文字体，兼容本地运行环境。
- 降低中文标签的字距与大写风格依赖，避免出现中文排版僵硬的问题。
- 适当放宽说明文字的宽度与行高，防止中文在信息卡与窄屏下过度挤压。

## 成功标准

- 主界面不再出现英文按钮、状态、说明或辅助提示。
- 运行中、胜利、失败、待机四种状态文案均为中文。
- `README` 能用中文说明在 VS Code 中如何运行和测试项目。
- 现有游戏逻辑与测试保持正常。
